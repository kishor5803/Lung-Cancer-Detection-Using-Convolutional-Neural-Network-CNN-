⚠️ Technical Calibration Requirement

Reliable clinical tumor size measurement requires calibrated medical imaging — typically volumetric CT/DICOM data with embedded voxel spacing metadata (PixelSpacing / SliceThickness) and a dedicated 3D segmentation network (e.g., U-Net / nnU-Net). A standard 2D CNN classification model alone cannot measure physical tumor size without explicit spatial calibration.
